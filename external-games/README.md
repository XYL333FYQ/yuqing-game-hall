# 第三方服务器游戏目录

这里仅保存无法作为本站静态运行包发布的第三方游戏 `game.json`。构建时，游戏厅读取这些 JSON，将简介编入前端目录；玩家启动游戏时直接打开 Manifest 中的 HTTPS 外部地址。

这个目录：

- 不复制到 Cloudflare Pages 的 `dist/`；
- 不复制到 VPS，也不包含可执行后端；
- 不代表第三方服务由本项目维护或保证可用；
- 不替代 `game-sources/upstream/` 中用于许可审查的上游源码归档。

若未来确实自建某款游戏，先把浏览器运行包拆到 `public/games/<id>/`，再把纯联机数据服务放到 `server-games/<id>/`；不能把同时提供整站静态页面的容器直接放进 VPS 数据层。
