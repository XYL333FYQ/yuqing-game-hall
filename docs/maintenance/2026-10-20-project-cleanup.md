## 已确认并修复的问题

| 问题 | 原因与修复 | 直接验证 |
| --- | --- | --- |
| 快速切换页面后旧页面覆盖新页面 | 动态导入完成后缺少有效路由检查；现在先取得渲染函数，再检查当前路由版本，过期的导入和过渡回调不再写入页面。 | 路由回归测试；真实浏览器延迟旧模块后切换到体感页。 |
| 地址片段包含单独 `%` 等非法编码时导航报错 | `decodeURIComponent` 会抛出异常；统一解码入口，失败时按字面 ID 查找。 | 导航测试；真实浏览器打开 `/vision-lab#%`。 |
| 斗地主零延迟 AI 连续回合递归过深 | AI 动作重复调用 `pump()`，把连续动作堆在同一调用栈；改为带重入保护的循环，保留普通延迟和轮次失效规则。 | 原有 960 局模拟与新增 300 局连续结算压力测试；人工玩家等待、计时取消、异常恢复等断言。 |
| 游戏目录未变化仍触发生成文件重写 | 测试、检查命令无条件写文件，可能触发现有开发页重载；现在内容相同时保留文件及修改时间。 | 真实 CLI 临时目录测试，同时验证清单变化仍更新结果。 |
| 编码检查放过非法 Unicode 序列 | 自写校验只检查续字节形状，未覆盖码点边界；使用 Node 内置严格 UTF-8 校验。 | 9 个 CLI 用例，覆盖过长编码、代理区、超范围、截断、合法多语言内容和原有跳过规则。 |

另外补齐了 `test:all` 原先遗漏的网关协议、网关冒烟和经典/追加游戏运行时测试。

网关测试在 Windows 上曾在断言通过后因强制退出触发原生句柄错误。测试服务改在子进程中运行，清理时调用真实关闭方法并等待子进程回收，客户端测试进程自然退出；生产网关没有改动。修复后主测试连续 30 次、冒烟连续 30 次通过。这是测试进程退出问题，不能据此推断生产服务存在同样缺陷。
