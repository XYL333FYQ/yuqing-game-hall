# 游戏源码分区

这里保存第三方项目的未修改上游仓库和淘汰记录，和真正参与主站构建的游戏代码严格分开。

## 目录规则

- `upstream/`：已经拉取并审查过的原始仓库。保持上游结构，只用于追溯、比较和后续同步，不进入 Cloudflare 构建。
- `rejected/`：已经明确淘汰的仓库或淘汰记录。移动前写清原因，避免以后重复筛选。
- 原生游戏放在 `games/<game-slug>/`，第三方静态移植放在 `public/games/<game-slug>/`，需要常驻后端的部署资料放在 `server-games/`。

## 当前流程

1. 原始仓库进入 `upstream/`，保持可追溯的上游结构。
2. 实际进入游戏检查玩法、启动链和运行资源，不只阅读 README。
3. 静态作品复制出清理后的运行包，再补中文层、许可和部署检查。
4. 联机作品保留独立服务边界，不能用空 iframe 冒充已部署后端。
5. 不合格项目移入 `rejected/`，许可证受限的项目只保留说明。

`upstream/` 和 `rejected/*/` 已被主项目 `.gitignore` 排除，避免嵌套仓库、依赖和大型美术资源污染主站版本。
